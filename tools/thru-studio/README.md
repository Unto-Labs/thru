# ⚡ Thru Studio & RISC-V VM Playground

An interactive smart program development playground, **RISC-V VM Simulator (RV32IM)**, and RPC Explorer for the **Thru Network**.

---

## 🌟 Key Features

- ⚡ **RISC-V VM Simulator**: Simulate atomic C smart program execution, compute cycles, and on-chain storage state mutations.
- 📜 **Program Templates**: Built-in templates for stateful counters and native token vaults.
- 🌐 **Interactive Web Studio**: Visual code editor, cycle counter, and memory viewer on `http://localhost:3410`.
- ⌨️ **Universal CLI (`thru-cli`)**: Terminal utility for network status inspection, program deployment, and execution.

---

## 🚀 Quickstart

```bash
# Launch Thru Studio
npm start
# Open http://localhost:3410

# Or run via CLI
node bin/thru-cli.js status
node bin/thru-cli.js exec
```
